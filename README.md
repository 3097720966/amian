# 微信手机（SillyTavern / TauriTavern 扩展）

页面上一个可拖拽的悬浮球，点开是一个只有「微信」的手机界面。聊天时会读取「记忆表格」插件里的数据，让角色按当前剧情回复。

没有 QQ、小红书、淘宝、朋友圈，也没有多余的功能按钮。

## 安装

酒馆 → 扩展 → 安装扩展 → 粘贴本仓库的 GitHub 地址。

## 使用

1. 点悬浮球打开手机，右上角齿轮进入设置。
2. **API 连接**：填服务器地址（OpenAI 兼容）、Key，点「获取模型」后选择模型。
3. **记忆表格**：确认读取到数据（见下）。
4. 回到会话列表，点角色开始聊天。当前在场的角色会排在最前并带「在场」标记。

## 怎么读取记忆表格

支持「记忆增强」的 chatSheets 格式（每张表第一行是表头、第一列是序号）。读取顺序：

1. **实时**：在最近 30 条聊天消息和聊天元数据里查找 chatSheets 形状的字段。
2. **导入的快照**：设置 → 记忆表格 → 导入表格文件，选记忆表格导出的 JSON。

设置页会显示当前用的是哪个来源。只有「事件历史」会被裁剪（导入时保留最后 60 行，聊天时再取最近 N 条，默认 15），避免占满上下文。

发给模型的内容：`当前信息`、`时间轴`、`房屋居住人员`、该角色自己的 `角色信息`（只带你勾选的列，默认不含外貌与隐藏信息）、最近 N 条 `事件历史`，以及可选的主线剧情最近几条。

## 数据保存

- 设置与微信聊天记录保存在酒馆的 `extensionSettings.WeChatPhone`（每个角色最多保留 80 条）。
- API Key 以明文存在酒馆设置里，请不要把 `settings.json` 分享给别人。

## 为什么比较轻

设置子页面点进去才创建、返回即销毁；没有毛玻璃；设置只通过酒馆标准接口保存，不会触发页面重载。
